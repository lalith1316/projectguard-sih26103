About ProjectGuard

A beginner-friendly prototype for SIH26103.

The idea

ProjectGuard brings basic project information into one simple dashboard and highlights possible cost, time and progress concerns.

Demo flow

1. Add project details → 2. Compare planned vs actual → 3. Assign Low / Medium / High risk → 4. Show the reason for concern.
