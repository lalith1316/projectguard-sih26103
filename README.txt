# ProjectGuard — SIH 2026 Demo

Problem Statement: SIH26103
Theme: Smart Automation

## What this is
A simple, self-contained browser prototype showing:
- Project dashboard
- Low / Medium / High risk indication
- Cost and progress checks
- Early warning explanation
- Add-project interaction
- Official PAIMANA reference

## Run locally
Double-click `index.html`. It works without installing anything and without internet.

## Publish as a public demo
Upload `index.html` to a static hosting service such as GitHub Pages, Vercel, or Netlify.

## Important
The risk calculation in this prototype is illustrative rule-based logic for demonstration. It is NOT an official MoSPI/PAIMANA risk score and does not claim to predict real projects.

## Suggested demo
Open Dashboard → Add Project → click CHECK PROJECT → change values → show how the risk indication changes.
